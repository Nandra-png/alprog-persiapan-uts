# AlProg UTS Review — COMP6421031

Static study site for Algorithm & Programming (COMP6421031), BINUS, UTS prep.
Built from the official Session 1–14 decks; no frameworks, no build step.

## Pages

- `index.html` — landing, deck map, review order
- `materi.html` — 7 modules: algorithm/flowchart/pseudocode, C syntax & formatted I/O,
  operators & precedence, selection, repetition, pointers & arrays, functions & recursion.
  Plus cheat sheet and a "10 jebakan nilai" section.
- `latihan.html` — 24 exam-style drills with collapsed answers and a dry-run tracing table.

## Structure

```
index.html      landing
materi.html     study book (inline CSS, notebook-paper layout)
latihan.html    drills
img/            slide renders referenced by materi.html
```

## Local

Open `index.html` in a browser. No server required.
