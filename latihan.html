Modul 1 · Algoritma, Flowchart & Pseudo-code

3 soal
Pseudo-code 1Rata-rata dengan sentinel

Buat pseudo-code gaya BINUS: baca bilangan bulat satu per satu sampai user memasukkan -1 (sentinel, tidak ikut dihitung), lalu tampilkan rata-ratanya.

Cek jawaban & rubrik 
STORE 0 TO total, count
INPUT num
DOWHILE num <> -1
    COMPUTE total = total + num
    COMPUTE count = count + 1
    INPUT num
ENDDO
IF count > 0 THEN
    COMPUTE avg = total / count
    PRINT "Rata-rata =", avg
ELSE
    PRINT "Tidak ada data"
ENDIF

Poin penuh kalau ada: (a) inisialisasi total dan count sebelum loop, (b) input kedua di dalam loop (kalau lupa, loop tak berujung), (c) penjaga count > 0 sebelum membagi — kalau tidak, pembagian dengan nol. Poin (c) yang paling sering dilupakan.

Flowchart 2Simbol dan fungsinya

Sebutkan simbol flowchart untuk: (a) mulai/selesai, (b) proses/kalkulasi, (c) input/output, (d) pengambilan keputusan, dan (e) penghubung antar-halaman.

Cek jawaban

(a) Terminator — oval/kapsul. (b) Process — persegi panjang. (c) Input/Output — jajar genjang. (d) Decision — belah ketupat, punya dua cabang keluar (Ya/Tidak). (e) Connector — lingkaran kecil berisi huruf/huruf angka.

Yang sering ketuker: decision selalu punya minimal 2 panah keluar. Kalau gambarnya belah ketupat tapi cuma 1 panah keluar, itu salah gambar dan biasanya dipotong nilainya.

Teori 3Structure theorem

Sebutkan 3 struktur kendali dasar yang cukup untuk membangun program apa pun, dan beri 1 contoh sintaks C untuk masing-masing.

Cek jawaban

1. Sequence — instruksi berurutan: a = 5; b = 7;

2. Selection — percabangan: if (a > b) ... else ...

3. Repetition — pengulangan: while (a < 10) { ... }

Kata kunci yang dicari dosen: "cukup". Artinya tidak ada struktur keempat yang dibutuhkan — switch, for, do-while semuanya bisa diturunkan dari tiga ini.

M2

Modul 2 · Sintaks C & Formatted I/O

4 soal
Tracing 4Lebar field printf

Output dari printf("%d|%5d|%-5d|%05d", 42, 42, 42, 42);

Cek jawaban 
42|   42|42   |00042

%d apa adanya. %5d rata kanan lebar 5 → 3 spasi + 42. %-5d rata kiri → 42 + 3 spasi. %05d lebar 5 diisi nol → 00042.

Hitung spasi persis. Kalau lu jawab " 42" (2 spasi) itu salah — %5d berarti total 5 karakter, jadi 3 spasi.

Jebakan 5%.2f pada pembagian bulat

Output dari printf("%.2f", 7 / 2);

Cek jawaban

3.00, bukan 3.50.

7 / 2 dievaluasi dulu sebagai pembagian integer → 3 (sisa 1 dibuang). Baru setelah itu hasil 3 diubah ke double untuk %f. Untuk dapat 3.50: 7.0 / 2 atau (double)7 / 2.

Ini soal paling sering keluar. Hafalin: tipe hasil operasi aritmatika ikut operand terbesar, dan int/int selalu int.

Tracing 6%c vs %d pada char

Kalau char c = 'A'; lalu printf("%c %d", c, c); — apa outputnya? Dan berapa nilai c + 1?

Cek jawaban

Output: A 65. Nilai c + 1 adalah 66 (int), dan (char)(c + 1) adalah 'B'.

Ingat: char di C sebenarnya bilangan bulat 1 byte. 'A' = 65, 'a' = 97, '0' = 48. Jadi 'a' - 'A' = 32, dan trik konversi huruf besar-kecil pakai selisih 32 itu sah.

Bug 7scanf menelan newline

User mengetik 25 lalu Enter, lalu B. Kode berikut kenapa tidak pernah menunggu input kedua?

scanf("%d", &umur);
scanf("%c", &gender);
Cek jawaban

Karena '\n' dari Enter pertama masih tertinggal di buffer. %c tidak melewati whitespace, jadi langsung mengambil '\n' itu sebagai nilai gender.

Fix: scanf(" %c", &gender); — spasi di depan format artinya "lewati semua whitespace dulu". Alternatif: panggil getchar(); sekali sebelum %c.

Catatan: %d, %f, %s otomatis melewati whitespace di depan. Hanya %c (dan %[) yang tidak.

M3

Modul 3 · Operator & Precedence

4 soal
Tracing 8Prefix vs postfix

Berapa nilai a, b, dan x?

int x = 5;
int a = x++;
int b = ++x;
Cek jawaban

a = 5, b = 7, x = 7.

Baris 2: x++ pakai nilai lama (5) untuk a, baru x jadi 6. Baris 3: ++x naikkan dulu x jadi 7, baru nilainya dipakai untuk b.

Kalau soal menulis x++ + ++x dalam satu ekspresi, jangan diberi satu jawaban pasti — itu undefined behavior. Jawaban yang benar secara akademik: urutan evaluasi tidak dijamin compiler, jadi hasilnya tidak bisa diprediksi. Dosen yang teliti akan menghargai jawaban ini.

Tracing 9Bagi dan modulo

Kalau a = 10 dan b = 3, apa hasil a / b dan a % b? Lalu kalau a = -10, berapa a % b?

Cek jawaban

3 dan 1. Untuk -10 % 3 hasilnya -1.

Aturan C (sejak C99): hasil modulo mengikuti tanda pembilang (yang dibagi), bukan penyebut. Jadi -10 % 3 = -1, bukan 2.

Konsekuensi praktis: cek bilangan ganjil dengan n % 2 == 1 akan gagal untuk bilangan negatif. Yang aman: n % 2 != 0.

Bitwise 10AND, OR, XOR

Hitung 12 & 10, 12 | 10, dan 12 ^ 10.

Cek jawaban

12 = 1100, 10 = 1010.

12 & 10 = 1000 = 8
12 | 10 = 1110 = 14
12 ^ 10 = 0110 = 6

Selalu tulis biner 4 bit di kertas buram, jangan hitung di kepala. Tips cepat: x ^ x = 0 untuk semua x.

Short-circuit 11&& memangkas evaluasi

Berapa nilai i setelah kode ini?

int i = 0;
if (i++ && i++) { }
printf("%d", i);
Cek jawaban

1.

Operand kiri i++ dievaluasi: nilai dipakai = 0 (false), i jadi 1. Karena hasil && sudah pasti false, operand kanan tidak dieksekusi — jadi i++ kedua tidak jalan.

Kalau operatornya | (bitwise OR, tidak short-circuit), dua-duanya dievaluasi dan i akan jadi 2. Ini perbedaan yang sering ditanyakan.

Modul 4 · Selection

3 soal
Tracing 12Switch tanpa break

Kalau x = 2, apa yang tercetak?

switch (x) {
  case 1: printf("A");
  case 2: printf("B");
  case 3: printf("C"); break;
  case 4: printf("D");
  default: printf("E");
}
Cek jawaban

BC.

Lompat ke case 2, cetak B. Tidak ada break → jatuh ke case 3, cetak C. Ketemu break → keluar. case 4 dan default tidak dijalankan.

Kenapa tidak cetak A? Karena switch melompat langsung ke label yang cocok, bukan mengecek dari atas satu per satu. Fall-through hanya terjadi ke bawah, tidak pernah ke atas.

Teori 13Dangling else

Pada if (a > 0) if (b > 0) printf("X"); else printf("Y"); — else itu milik if yang mana? Apa outputnya kalau a = -1 dan b = 5?

Cek jawaban

else milik if (b > 0) — if terdekat yang belum punya pasangan.

Kalau a = -1: syarat pertama false, jadi seluruh blok if(b) dilewati — tidak ada output sama sekali. else tidak ikut dieksekusi karena dia ada di dalam blok yang dilewati.

Untuk membuat else jadi milik if luar, wajib pakai kurung kurawal: if (a > 0) { if (b > 0) printf("X"); } else printf("Y");

Jebakan 14if dengan tanda sama dengan

Apa output dari int x = 0; if (x = 5) printf("MASUK"); else printf("LEWAT");

Cek jawaban

MASUK.

x = 5 adalah penugasan, bukan perbandingan. Ekspresinya bernilai 5, dan di C semua nilai non-zero dianggap true. Jadi blok if selalu jalan dan x sekarang berisi 5.

Cara nangkep bug ini: tulis konstanta di kiri — if (5 == x). Kalau typo jadi if (5 = x), compiler langsung error karena tidak bisa menugaskan ke konstanta.

M5

Modul 5 · Repetition

3 soal
Jebakan 15Titik koma setelah for

Apa output dari int i; for (i = 0; i < 5; i++); printf("%d", i);

Cek jawaban

5, dan cuma tercetak sekali.

Titik koma di ujung header jadi bodi loop kosong — loop tetap berputar 5 kali tanpa melakukan apa pun, sampai i = 5 dan kondisi gagal. Baru setelah itu printf jalan sekali.

Kalau soalnya printf tanpa titik koma tambahan, outputnya 01234. Bedanya cuma satu karakter — makanya soal ini jadi favorit.

Tracing 16Nested loop berperingkat

Berapa banyak karakter * yang tercetak?

for (i = 1; i <= 3; i++)
    for (j = 1; j <= i; j++)
        printf("*");
Cek jawaban

6 bintang (i=1 → 1, i=2 → 2, i=3 → 3; total 1+2+3 = 6).

Kalau ada printf("\n") di akhir loop dalam, hasilnya segitiga:

*
**
***

Rumus cepat: total iterasi nested loop = penjumlahan batas dalam untuk setiap nilai luar. Jangan dikalikan (3×3=9 itu salah).

Tracing 17do-while jalan minimal sekali

Apa output dari int i = 10; do { printf("%d ", i); i++; } while (i < 5);

Cek jawaban

10 — sekali saja.

Bodi selalu dieksekusi dulu, baru kondisi dicek. Saat cek, i sudah 11 dan 11 < 5 false → berhenti.

Kalau ditulis while (i < 5) biasa, outputnya kosong sama sekali. Inilah satu-satunya perbedaan perilaku yang diuji dari do-while.

Modul 6 · Pointer & Array

4 soal
Pointer 18Aritmatika pointer

Apa output dari int a[] = {10,20,30}; int *p = a; printf("%d %d", *(p + 2), *p + 2);

Cek jawaban

30 12.

*(p + 2): geser pointer 2 elemen dulu, baru dereference → a[2] = 30.
*p + 2: dereference dulu (a[0] = 10), baru ditambah 2 → 12.

Kuncinya urutan operator: * dan + — kurung menentukan mana yang duluan. Tanpa kurung, * lebih tinggi dari +, jadi *p+2 selalu (*p)+2.

Array 19Inisialisasi sebagian

Isi a[0] sampai a[4] untuk int a[5] = {1, 2}; — dan apa isi a[5]?

Cek jawaban

1, 2, 0, 0, 0. Elemen yang tidak diinisialisasi diisi nol.

a[5] di luar batas — undefined behavior. Bisa berisi sampah memori, bisa crash, bisa kebetulan 0. Jawaban "0" salah, karena itu bukan jaminan bahasa.

Catatan: array lokal tanpa inisialisasi sama sekali (int a[5];) berisi sampah, bukan nol. Nol hanya berlaku kalau ada inisialisasi sebagian atau static.

String 20strlen vs sizeof

Untuk char s[] = "BiNus"; — berapa strlen(s) dan sizeof(s)?

Cek jawaban

strlen(s) = 5, sizeof(s) = 6.

sizeof menghitung total byte array termasuk '\0'. strlen menghitung karakter sampai ketemu '\0', jadi tidak termasuk.

Konsekuensi: kalau mau gabung dua string, ukuran tujuan minimal strlen(a) + strlen(b) + 1. Lupa +1 = buffer overflow.

2D Array 21Row-major offset

Untuk int m[3][4]; — berapa selisih alamat antara &m[1][2] dan &m[0][0]?

Cek jawaban

6 elemen (kalau dihitung byte: 6 × 4 = 24 byte untuk int 4 byte).

Rumus: offset = i * jumlah_kolom + j = 1×4 + 2 = 6. C menyimpan array 2D secara row-major: baris 0 dulu lengkap, baru baris 1.

Kalau di soal ada int *p = &m[0][0]; maka p[6] adalah elemen yang sama dengan m[1][2]. Inilah kenapa parameter fungsi 2D wajib menyebut jumlah kolom: void f(int a[][4]) — tanpa 4, compiler tidak tahu cara menghitung offset.

Modul 7 · Function & Recursion

3 soal
Rekursi 22Trace faktorial

Kalau int f(int n) { if (n <= 1) return 1; return n * f(n - 1); } — berapa f(4), dan berapa kali fungsi dipanggil total?

Cek jawaban

f(4) = 24. Total pemanggilan: 4 kali (f(4), f(3), f(2), f(1)) — f(1) langsung mengembalikan 1 tanpa memanggil lagi.

Jejak: 4 × f(3) = 4 × (3 × f(2)) = 4 × 3 × (2 × f(1)) = 4 × 3 × 2 × 1 = 24.

Untuk soal "berapa kedalaman stack", jawabannya 4 level. Untuk n besar, rekursif bisa stack overflow — versi iteratif pakai satu variabel akumulator lebih hemat memori.

Passing 23Pass by value tidak mengubah asli

Setelah void ubah(int x) { x = 99; } dipanggil dengan int a = 5; ubah(a); — berapa nilai a?

Cek jawaban

Tetap 5.

C menyalin nilai a ke parameter x. x adalah variabel berbeda di memori lain — mengubahnya tidak menyentuh a.

Supaya berubah, kirim alamat: void ubah(int *x) { *x = 99; } lalu panggil ubah(&a);.

Pengecualian penting: array selalu lewat alamat. Kalau parameternya void ubah(int x[]), perubahan x[0] ikut mengubah array asli.

Teori 24Rekursi tanpa base case

Apa yang terjadi kalau fungsi rekursif lupa menulis base case? Dan sebutkan 2 syarat wajib rekursi.

Cek jawaban

Fungsi memanggil dirinya terus-menerus sampai stack overflow — program crash (segmentation fault), bukan menghasilkan output salah.

Dua syarat wajib: (1) base case — kondisi yang berhenti tanpa rekursi, (2) reduction step — argumen harus bergerak menuju base case. Kalau base case ada tapi argumen tidak mengecil (f(n) memanggil f(n)), hasilnya sama: infinite recursion.

Contoh base case faktorial: if (n <= 1) return 1; — tanpa baris ini, n terus turun ke negatif dan tidak pernah berhenti.
