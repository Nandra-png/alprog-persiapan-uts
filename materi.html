Persiapan UTS Algorithm & Programming (COMP6421031)

Kurikulum BINUS · Dosen: Moh. Erdda Habiby, S.ST, M.Kom. · Referensi: Deitel & Deitel (C How to Program 8th ed)
Aturan main ujian AlProg BINUS:

1. Format Penulisan Sangat Ketat: Pada bagian pseudo-code, BINUS memakai notasi kapital: INPUT, OUTPUT, COMPUTE, STORE, DOWHILE ... ENDDO, IF ... THEN ... ELSE ... ENDIF. Menulis gaya bahasa pemrograman lain (Python/JS) langsung dipotong nilai.

2. Tracer Table (Dry Run): Untuk soal tracing loop / array / pointer, jangan cuma tulis output akhir! Kolom variabel iterasi, kondisi perulangan, dan isi buffer wajib lu tampilkan rapi.

3. Zero Tolerance String Null-Terminator: Array karakter di C wajib berakhiran '\0'. Mengalokasikan array ukuran N untuk menampung teks N huruf adalah bug fatal klasik.

Peta 7 Topik Inti Ujian

1. Algorithm, Flowchart & Pseudo-code (Sesi 1-2): Analisis IPO (Input-Process-Output), simbol terminator/decision/preparation, Structure Theorem (Sequence, Selection, Repetition).

2. Sintaks Dasar C & Formatted I/O (Sesi 3-4): Struktur fungsi main(), tokens, escape sequences, specifier %d, %f, %.2f, %c, %s, %[^ ], pembersihan buffer getchar().

3. Operator & Precedence (Sesi 5-6): Arithmetic, relational, logical short-circuit (&&, ||), prefix vs postfix (++x vs x++), bitwise (&, |, ^, ~, <<, >>).

4. Selection Control (Sesi 7): Nested if, dangling else problem, switch-case fall-through (wajib hafal perilaku jika break lupa ditulis).

5. Repetition Control (Sesi 8): for, while, do-while (minimal 1 kali eksekusi), loop berperingkat (nested loop), sentinel value, break vs continue.

6. Pointer & Arrays (Sesi 9-10): Hubungan arr[i] dengan *(arr + i), pointer constant vs pointer variable, array 2D row-major, manipulasi string (string.h: strlen, strcpy, strcmp, strcat).

7. Function & Recursion (Sesi 13-14): Passing parameter by-value vs by-reference (pointer), function prototype, variable scope (local vs global), recursive call stack & base case.

Kamus Soal: Kalimat Ujian → Harus Ngapain

Baca ini dulu sebelum buka modul. Ini yang bikin lu nggak blank waktu membaca lembar soal.
1"Tuliskan Pseudo-code dan Flowchart untuk memvalidasi..."
Contoh: "Buat algoritma sistem kasir yang membaca kode barang 10 digit, berhenti jika kode bernilai 0000000000."
Arti sebenarnya: Dosen mau menguji kemampuan dekomposisi IPO (Input-Process-Output) dan penerapan loop sentinel.
  • Tentukan input: productCode, qty, price.
  • Tentukan terminator loop: berhenti jika productCode == "0000000000".
  • Pakai kata kunci BINUS resmi: DOWHILE ... ENDDO atau WHILE ... ENDWHILE.
Tindakan: Gambar belah ketupat (decision) untuk cek sentinel, jajar genjang (I/O) untuk input kasir, persegi panjang untuk akumulator total = total + (qty * price).
2"Tentukan Output dari Potongan Kode Berikut (Dry Run / Tracing)"
Contoh: Soal dengan operasi pre-increment campuran di dalam ekspresi aritmatika atau rekursif bersarang.
Arti sebenarnya: Dosen mencari apakah lu terjebak di urutan evaluasi (associativity) dan efek samping (side effects).
  • Tulis tabel tracing berisi: No baris, Nilai variabel tiap langkah, Output di layar.
  • Pre-increment (++x): tambahkan 1 dulu ke variabel, baru nilainya dipakai dalam ekspresi.
  • Post-increment (x++): pakai nilai lama dalam ekspresi, setelah itu baru variabel naik 1.
Tindakan: Jangan hitung di kepala. Buat 3 kolom di kertas buram: Langkah | Nilai Var | Layar.
3"Buat Fungsi Rekursif untuk Menghitung..."
Contoh: Faktorial, deret Fibonacci, perkalian via penjumlahan berulang, atau pembalik string.
Arti sebenarnya: Validasi 2 syarat mutlak rekursi: Base Case (kondisi stop tanpa rekursi) dan Reduction Step (parameter harus mengecil menuju base case).
Tindakan: Tulis if (base_condition) return nilai_tetap; paling atas, baru diikuti return f(n-1) ....

Modul 1 · Algorithm, Flowchart & Pseudo-code (Sesi 1-2)

Slide Resmi: 01_algoprg_flowchart_pseudocode.pptx (40 slide) · Sesi 1-2

Analogi: Resep Masak Presisi

Komputer itu juru masak buta dan tuli. Algoritma adalah urutan langkah terstruktur yang tidak meninggalkan celah tafsir ganda. Kalau lu bilang "tambahkan garam secukupnya", itu bukan algoritma. Kalau lu bilang "tambahkan 5 gram garam saat air mencapai 100°C", itu algoritma.

1. Alur Pemecahan Masalah (Development Steps)

Di slide 6 BINUS, tahapan pemecahan masalah memakai komputer ada 6 tahap terstandar:

1
Problem Definition: Identifikasi masalah secara jelas (apa input yang tersedia, apa output yang diminta).
2
Model Development: Rumus matematika atau model logika (misal persamaan kuadrat ax² + bx + c = 0, hitung diskriminan d = b² - 4ac).
3
Algorithm Design: Representasi logika lewat Flowchart atau Pseudo-code sebelum menulis sintaks bahasa.
4
Writing Code: Mengubah algoritma ke Source Code (bahasa C).
5
Compile & Run: Kompilasi ke file executable. Jika ada Syntax Error perbaiki, jika ada Output / Logic Error perbaiki alurnya.
6
Documentation: Dokumentasi kode agar mudah dirawat.

3. Structured Program Theorem

Semua program di dunia, sekompleks apapun, hanya dibangun dari 3 struktur kendali dasar:

1. Sequence: Eksekusi sekuensial instruksi demi instruksi dari atas ke bawah.

2. Selection: Percabangan alur berdasarkan pengujian nilai kebenaran (IF, IF-ELSE, SWITCH).

3. Repetition: Pengulangan blok instruksi selama kondisi terpenuhi (FOR, WHILE, DO-WHILE).

Bahasa C bersifat case-sensitive. Eksekusi program selalu dimulai dari fungsi main(). Di standar ujian BINUS, bentuk standar penulisan yang diakui resmi adalah:

3. Formatted Input & Masalah Buffer scanf
Jebakan Klasik scanf: Buffer Newline Tertinggal!

Ketika lu mengetik angka lalu menekan Enter, karakter \n masih tertinggal di input buffer. Jika baris berikutnya membaca %c atau string, scanf akan langsung menelan karakter newline tersebut dan melewatinya tanpa menunggu input user!

Solusi Resmi Ujian: Gunakan spasi sebelum %c atau panggil getchar():

int umur;
char gender;
scanf("%d", &umur);
scanf(" %c", &gender); /* Perhatikan SPASI sebelum %c */
4. Format Output printf: Width & Precision

Sintaks lengkap: %[flags][width][.precision]type

  • printf("%6d", 34); → Menghasilkan 34 (rata kanan, lebar 6 kolom).
  • printf("%-6d", 34); → Menghasilkan 34 (rata kiri, ada tanda minus).
  • printf("%8.2f", 3.14159); → Menghasilkan 3.14 (lebar 8 kolom, 2 angka di belakang koma).
  • Membaca string ber-spasi: scanf("%[^ ]", str); (membaca seluruh kalimat sampai tombol enter).

Modul 3 · Operator, Operand & Precedence (Sesi 5-6)

Slide Resmi: 05_operator_operand_aritmatika.pptx (37 slide) · Sesi 5-6
1. Pre-increment (++x) vs Post-increment (x++)

Perbedaan kedua operator ini mutlak dikuasai untuk soal-soal tracing tracing kode:

  • Pre-increment (++x): Nilai x dinaikkan 1 dulu, kemudian nilai barunya dipakai dalam ekspresi.
  • Post-increment (x++): Nilai x yang lama dipakai dulu dalam perhitungan, setelah baris/sub-ekspresi itu selesai baru nilai x bertambah 1.
BEDAH KASUS EKSPRESI TERIKAT 
int x = 44, y = 44;
int z1 = ++x; /* x jadi 45, lalu z1 diisi 45 */
int z2 = y++; /* z2 diisi nilai lama 44, setelah itu y jadi 45 */
2. Operator Bitwise (Operasi Bit per Bit)
OperatorNamaPenjelasanContoh (A=24=011000b, B=35=100011b)
&Bitwise AND1 jika kedua bit bernilai 124 & 35 = 0 (000000b)
|Bitwise OR1 jika salah satu atau kedua bit bernilai 124 | 35 = 59 (111011b)
^Bitwise XOR1 jika kedua bit BERBEDA45 ^ 75 = 102 (slide 23)
~Complement (NOT)Membalik semua bit 0 jadi 1 dan 1 jadi 0~0xC3 = 0x3C (slide 24)
<<Shift LeftGeser bit ke kiri (mengalikan 2^n)78 << 2 = 312 (78 * 4)
>>Shift RightGeser bit ke kanan (membagi bulat 2^n)78 >> 3 = 9 (78 / 8)
3. Short-Circuit Evaluation pada Operator Logika

Pada bahasa C, operator logika && (AND) dan || (OR) dievaluasi dari kiri ke kanan dengan sifat pemangkasan cepat (short-circuit):

  • Pada A && B: Jika ekspresi A bernilai FALSE (0), maka ekspresi B TIDAK AKAN PERNAH DIEKSEKUSI karena hasil akhir pasti FALSE.
  • Pada A || B: Jika ekspresi A bernilai TRUE (non-zero), maka ekspresi B TIDAK AKAN DIEKSEKUSI karena hasil akhir pasti TRUE.

Modul 4 · Program Control: Selection (Sesi 7)

Slide Resmi: 07_program_control_selection.pptx (36 slide) · Sesi 7
1. Bentuk-Bentuk Percabangan

C mendukung 3 struktur pemilihan keputusan: if, if-else, dan switch-case, serta operator ternary ? :.

2. Switch-Case & Bahaya Fall-Through
Jebakan switch-case tanpa break!

Di dalam blok switch, label case hanyalah penanda titik lompat. Jika sebuah case cocok dan di dalamnya tidak terdapat perintah break;, program akan terus mengeksekusi semua case di bawahnya tanpa mempedulikan kondisi lagi (fall-through)!

CONTOH FALL-THROUGH DARI DECK RESMI 
int x = 2;
switch(x) {
    case 1: printf("A");
    case 2: printf("B"); /* Masuk sini karena x == 2 */
    case 3: printf("C"); break; /* Lanjut cetak C lalu BREAK */
    case 4: printf("D");
    default: printf("E");
}
/* Output yang tercetak di layar: BC */
3. Jenis-Jenis Error pada Pemrograman C (Slide 25)
  • Compile-Time Error: Kesalahan sintaks kode (titik-koma hilang, typo variabel). Dideteksi saat kompilasi.
  • Link-Time Error: Terjadi saat proses linking (misal lupa menyertakan prototipe library atau nama fungsi salah panggil).
  • Run-Time Error: Program lolos kompilasi tapi crash saat berjalan (pembagian dengan nol, overflow memori).
  • Logical Error: Program berjalan lancar tanpa crash, tapi rumus atau logika salah sehingga output keliru. Ini adalah error paling sulit didebug!

2. Break vs Continue

  • continue; → Mengabaikan sisa instruksi di iterasi saat ini dan langsung melompat ke pengecekan kondisi / kenaikan iterasi berikutnya.
DRILL RESMI SLIDE 28 & 29

    printf("%d ", x);

/* Kasus BREAK: Berhenti total saat x == 5 */
for(x=1; x<=10; x++) {
    if (x == 5) break;
    printf("%d ", x);
}
/* Output: 1 2 3 4 */

Modul 6 · Pointers and Arrays (Sesi 9-10)

Slide Resmi: 09_pointers_arrays.pptx (40 slide) · Sesi 9-10

Analogi: Rumah vs Alamat Rumah

Variabel biasa seperti sebuah rumah yang berisi perabotan. Pointer adalah selembar kertas yang bertuliskan koordinat GPS rumah tersebut. Operator & (address-of) digunakan untuk mencari alamat rumahnya. Operator * (dereference) dipakai untuk pergi ke alamat itu dan mengambil perabotan di dalamnya.

1. Pointer Constant vs Pointer Variable
Array Nama adalah Pointer Constant!

Jika dideklarasikan int B[4]; dan int *ptr;:

  • ptr = B; → BENAR (alamat elemen pertama disalin ke pointer).
  • ptr++; → BENAR (pointer variable bisa bergeser ke elemen berikutnya).
  • B = ptr; → ERROR! B adalah pointer konstan (alamat array tidak boleh diubah).
  • B++; → ERROR! Alamat fisik awal array tidak bisa digeser.
2. Akses Elemen: Notasi Index vs Aritmatika Pointer

Dua penulisan ini 100% identik di mata compiler C:

arr[i] ≡ *(arr + i)
&arr[i] ≡ (arr + i)

Untuk array 2 dimensi matrix[row][col]:

matrix[i][j] ≡ *(*(matrix + i) + j)
3. Fungsi Manipulasi String Standar (string.h)

Modul 7 · Function and Recursion (Sesi 13-14)

Slide Resmi: 13_function_recursion.pptx (44 slide) · Sesi 13-14
1. Function Prototype & Urutan Kompilasi

Jika sebuah fungsi didefinisikan di bawah fungsi pemanggilnya (main()), compiler C memerlukan Function Prototype di atas main() agar mengenali tipe kembalian dan jumlah serta tipe parameternya.

#include <stdio.h>

/* Prototipe Fungsi */
int hitungMaks(int a, int b);

int main() {
    int m = hitungMaks(10, 25);
    return 0;
}

int hitungMaks(int a, int b) {
    return (a > b) ? a : b;
}
2. Passing Parameter: By Value vs By Reference
  • Pass by Value: Nilai variabel disalin. Perubahan pada parameter formal di dalam fungsi TIDAK mengubah nilai variabel asli di pemanggil.
  • Pass by Reference (Location): Alamat memori variabel dikirim menggunakan pointer. Perubahan nilai di dalam fungsi AKAN MERUBAH variabel asli di pemanggil.
3. Rekursi: Base Case & Call Stack

Fungsi rekursif memanggil dirinya sendiri. Dua bagian wajib rekursif:

  1. Base Case: Kondisi penghenti yang langsung mengembalikan nilai konstan tanpa pemanggilan rekursif lagi.
  2. Reduction Step: Pemanggilan rekursif dengan argumen yang konvergen / semakin mendekati base case.

10 Jebakan Nilai AlProg (Wajib Dibaca Sebelum Ujian)

Dihimpun dari pola kesalahan fatal mahasiswa BINUS di semester-semester sebelumnya.
1Pembagian Bulat (Integer Division Truncation)
Menulis float x = 7 / 2; menghasilkan nilai berapa?
Jawab: 3.000000, bukan 3.5! Karena kedua operan adalah integer, pembagian bulat dilakukan terlebih dahulu menghasilkan 3, baru diubah jadi float. Tulis 7.0 / 2 atau (float)7 / 2.
2Operator Kesetaraan (==) vs Penugasan (=)
Menulis if (x = 5) { ... } di dalam pengujian logika.
Jawab: Selalu TRUE! Tanda = memasukkan angka 5 ke dalam variabel x. Di C, angka non-zero dianggap TRUE, sehingga blok di dalam if akan selalu berjalan. Gunakan selalu == untuk perbandingan.
3Dangling Else Problem pada Nested If
Pada struktur if (a) if (b) s1; else s2;, klausa else milik siapa?
Jawab: Milik if kedua! Bahasa C selalu memasangkan else dengan if terdekat yang belum memiliki pasangan, kecuali dikurung dengan kurung kurawal { }.
4Perulangan for Berakhir Titik Koma (;)
for(i=0; i<10; i++); printf("%d", i);
Jawab: Hanya mencetak 10 sekali! Tanda titik koma di ujung header for membuat perulangan berjalan dengan bodi kosong sampai i == 10.
5Array Index Out of Bounds (Off-By-One)
Array int a[10]; diakses sampai a[10].
Jawab: Undefined Behavior / Crash! Indeks array C dimulai dari 0 sampai N - 1. Untuk ukuran 10, indeks valid adalah 0 sampai 9. Mengakses a[10] membaca memori liar di luar array.
6strcmp Sama = 0, Bukan 1
Dua string identik dibandingkan dengan strcmp(s1, s2).
Jawab: return 0! Nilai 0 berarti "tidak ada selisih". Banyak yang salah pakai if (strcmp(a,b)) lalu mengira itu true saat sama — justru kebalikannya. Yang benar: if (strcmp(a,b) == 0).
7sizeof(array) vs sizeof(pointer)
int a[10]; printf("%d", sizeof(a)/sizeof(a[0])); lalu hal sama dilakukan di dalam fungsi.
Jawab: 10 di main, tapi 2 (atau 1) di dalam fungsi! Saat array dikirim ke fungsi, ia meluruh (decay) menjadi pointer. sizeof jadi ukuran pointer, bukan total array.
8scanf("%s") Berhenti di Spasi
Input user: Good Morning, dibaca dengan scanf("%s", s).
Jawab: s hanya berisi "Good"! %s berhenti di karakter whitespace pertama. Untuk satu baris penuh pakai gets(s) atau scanf(" %[^ ]", s).
9Bandingkan float dengan ==
if (0.1 + 0.2 == 0.3)
Jawab: FALSE! Floating point disimpan dalam biner, jadi ada galat pembulatan halus. Bandingkan dengan selisih toleransi: fabs(a - b) < 1e-9.
10'A' vs "A"
Berapa sizeof('A') dan sizeof("A")?
Jawab: 4 dan 2! 'A' adalah int (nilai 65) di C, sedangkan "A" adalah array char berisi dua elemen: 'A' dan '\0'.
